# Drive Cinematic Design

GET RADIO PRO — SITE SPEC

Build a premium, cinematic, conversion-focused 4-page website for GET RADIO PRO, a modern car radio, infotainment and audio upgrade brand.

Pages:

Home

About

Services

Contact

DESIGN DIRECTION

Create a unique premium automotive-tech experience, not a generic car-audio template.

Style:

Dark black/charcoal automotive aesthetic

White/off-white typography

One sophisticated accent color

Cinematic car interior photography

Premium touchscreen/radio visuals

Sharp modern typography

Large bold headlines

Clean spacing

Subtle glass/metal UI details

Smooth scroll animations

Premium micro-interactions

Avoid generic SaaS layouts, excessive gradients, excessive rounded cards, cheap neon effects, stock-looking imagery and repetitive card grids.

The website should feel like a professional automotive technology campaign, similar in quality to a high-end car brand website.

Create an original professional logo for GET RADIO PRO.

No generic music-note icon

Header

Footer

Favicon
